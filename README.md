# Blog-homepage
하나샘논술 블로그를 홈페이지로 재구성

동수원자이 1차 114동 한우리 독서토론논술 교실(하나샘) 홈페이지입니다.
원본 블로그: https://blog.naver.com/hanabee114

## 구성
- `index.html` : 홈페이지 본문 (선생님 소개, 우리 교실의 차별점, 수업 이야기, 상담 안내)
- `css/style.css` : 디자인 (초록·테라코타·미색 계열, 파란색 미사용)
- `js/posts.js` : 블로그 글 목록 — 요약(summary)은 직접 고쳐도 됩니다.
- `js/main.js` : 메뉴, 학년별 분류 기능
- `images/posts/` : 블로그 글 표지 그림
- `scripts/update_posts.py` : 블로그에서 새 글 가져오기

## 새 글 가져오기
블로그에 새 글을 올린 뒤 아래 명령을 실행하면 새 글과 표지 그림이 홈페이지에 추가됩니다.

```
python3 scripts/update_posts.py
```

- ‘114동 한우리의 차별점’ 분류의 글은 ‘우리 교실의 차별점’ 칸에,
- 나머지 분류(초등학교 ○학년 수업, 중학교 수업 등)의 글은 ‘수업 이야기’ 칸에 학년별로 나타납니다.

`index.html`을 브라우저로 열면 바로 확인할 수 있습니다.
